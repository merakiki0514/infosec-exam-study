# 정보보안기사 실기 일일 학습 세션

이 스킬은 `/home/sy/LLM/Study` 프로젝트의 문제 데이터베이스(`data/questions.json`)와 학습 계획(`docs/study-plan.md`)을 이용해 하루 2~3시간 분량의 주관식·실무형 학습 세션을 진행한다.

## 인자 해석

사용자가 `/study` 뒤에 붙이는 인자를 다음과 같이 해석한다.

- 인자 없음: 일반 세션. `docs/study-plan.md`의 로드맵과 오늘 날짜를 참고해 적절한 주제를 고르거나, 사용자에게 오늘 진행할 주제를 짧게 물어본다.
- 주제 코드(`network`, `web`, `system`, `crypto`, `risk`, `law`): 해당 주제만 출제.
- `review`: 이전에 틀리거나 애매했던(wrong/partial) 문제만 재출제.
- `weak`: 지금까지 정답률이 가장 낮은 취약 주제 1~2개를 자동으로 골라 출제.

## 진행 절차

1. **문제 선택**: `scripts/quiz.py`를 사용해 문제를 뽑는다. 직접 JSON을 파싱하지 말고 반드시 이 스크립트를 통해서 뽑는다 (진행 이력 기반 우선순위 로직이 이미 구현되어 있음).

   ```bash
   python3 scripts/quiz.py pick --topic <topic> --count 8 --mode normal
   ```

   - 기본 문항 수는 8~12개 (2~3시간 세션에 적합한 분량). 단답형/서술형/실무형이 고르게 섞이도록 결과를 확인하고, 한쪽으로 너무 치우치면 다시 뽑거나 수동으로 조정한다.
   - `--source 예상`을 섞어서 가끔(전체의 20% 이내) 예상문제도 포함시킨다.

2. **출제**: 문제를 한 번에 다 보여주지 말고, 1문제씩 순서대로 제시한다. 문제 유형(단답형/서술형/실무형)과 출처(연도-회차 또는 예상문제)를 함께 표시한다. 사용자가 답을 입력할 때까지 기다린다.

3. **채점**: 사용자의 답변을 `data/questions.json`의 `a`(모범답안)와 `keywords`(핵심 키워드)에 비추어 채점한다.
   - **correct**: 핵심 키워드와 논리가 대부분 포함된 경우
   - **partial**: 방향은 맞지만 핵심 키워드가 빠졌거나 불완전한 경우
   - **wrong**: 핵심을 벗어났거나 답하지 못한 경우
   - 채점 후 모범답안을 보여주고, 부족한 부분을 짧게 피드백한다. 정보보안기사 실기는 키워드 포함 시 부분점수를 주므로, 완벽한 문장이 아니어도 핵심 키워드가 있으면 correct/partial로 판단할 것.
   - 채점 즉시 기록한다:

     ```bash
     python3 scripts/quiz.py record --id <question_id> --result correct|partial|wrong
     ```

4. **세션 마무리**: 모든 문제를 마치면 `python3 scripts/quiz.py stats`로 주제별 정답률을 보여주고, 오늘 틀린/애매했던 문제의 핵심 키워드를 다시 한번 요약해준다. 다음 세션에서 무엇을 복습하면 좋을지 한 줄로 제안한다.

## 참고 자료 우선순위

문제의 배경 개념을 더 설명해야 할 때는 `docs/concepts/`의 해당 주제 파일을 참고한다 (예: network → `docs/concepts/01-network.md`). 정확한 기출 원문이 필요하면 `docs/past-exams/`를 참고한다.

## 주의사항

- `data/questions.json`이나 `progress/progress.json`을 스킬 실행 중 직접 수정하지 말 것 — 반드시 `scripts/quiz.py`를 통해서만 갱신한다 (동시 수정으로 인한 데이터 손상 방지).
- 세션은 대화형으로 진행한다. 한꺼번에 모든 문제와 답을 쏟아내지 말고, 실제 시험처럼 한 문제씩 풀게 한다.
- 사용자가 도중에 그만두고 싶어하면 지금까지 푼 문제까지만 기록하고 짧게 요약한 뒤 종료한다.
