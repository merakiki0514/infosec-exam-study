## 9. 위험분석 관련 문제

(A) 가용성 / (B) 그룹핑

- **자산 가치 평가**: 자산이 식별되면 자산별 기밀성, 무결성, 가용성 측면에서 중요도를 산정하고 중요도에 따라 자산의 가치를 평가. (중요도를 산정하는 이유) 식별된 자산에 위험 발생 시의 영향을 기밀성, 무결성, 가용성 측면에서 파악하여 자산의 가치를 평가하기 위함
- **자산 그룹핑**: 자산의 가치가 결정되면 유형, 중요도, 사용 용도, 위험 등이 유사한 자산들을 하나의 그룹으로 만들어 분류. (그룹핑하는 이유) 유형, 중요도 등이 유사한 자산을 그룹핑하여 동일한 위험분석 및 평가 작업을 반복하지 않음으로써 시간과 비용을 최소화

## 14. 윈도우 NetBIOS 관련 문제

**(A) 취약한 이유**: 인터넷에 직접 연결된 윈도우 시스템에서 NetBIOS와 TCP/IP 바인딩이 활성화되어 있으면 인터넷을 통해 외부 공격자가 윈도우 시스템의 네트워크 공유자원에 접근할 수 있는 취약점이 발생

**(B) 보안 설정 방법**: 네트워크 제어판을 이용하여 NetBIOS와 TCP/IP 간 바인딩을 제거 — `ncpa.cpl`(네트워크 연결 제어판) 실행 > 네트워크 인터페이스 선택 > TCP/IPv4 속성에서 고급 설정 선택 > WINS 탭에서 "NetBIOS over TCP/IP 사용 안함" 선택

## 15. IPsec 정의와 2가지 동작 모드

**(A) 정의**: 종단 노드 구간(End Point) 또는 보안/터널 게이트웨이(Security/Tunnel Gateway) 구간에 IP 패킷 보안 서비스를 제공해 주는 네트워크 계층 보안(터널링/VPN) 프로토콜

**(B) 동작 모드**

1. 전송 모드(Transport Mode): IP 패킷의 페이로드(Payload)를 보호하는 모드로, 일반적으로 종단 노드 구간의 IP 패킷 보호를 위해 사용
2. 터널 모드(Tunnel Mode): IP 패킷 전체를 보호하는 모드로, 일반적으로 양쪽 터널 게이트웨이 또는 종단 노드와 터널 게이트웨이 구간의 IP 패킷 보호를 위해 사용

## 16. 위험관리의 중요도

**(A) 중요도 산정 개념**: 위험분석을 위해 식별된 정보 자산에 대해 침해 사고(위협) 발생 시 다양한 측면의 영향을 파악하여 자산의 가치를 평가하는 것을 중요도 산정이라 한다.

**(B) 필수 기준 3가지**: 정보자산의 중요도를 산정하기 위해서는 자산을 안전하게 보호하기 위해 요구되는 특성을 파악해야 하며, 이러한 특성에는 일반적으로 기밀성, 무결성, 가용성이 포함됨. 기밀성은 정보 유출 측면에서, 무결성은 정보 변조 측면에서, 가용성은 정보 상실(또는 서비스 제공) 측면에서 자산에 보장되어야 하는 특성을 말한다.

- 기밀성: 정보 자산의 접근은 인가된 사용자만이 접근할 수 있음을 보장해야 하는 특성(정도)
- 무결성: 정보 자산 내 정보 및 처리 방법의 정확성, 완전성을 보호해야 하는 특성(정도)
- 가용성: 인가된 사용자가 필요시 정보 자산 및 관련 정보에 접근하는 것을 보장하는 특성(정도)

## 17 (실무형). 로그인 배너 취약점

**(A) 보안 취약점**: 로그인 배너가 설정되지 않을 경우 배너에 서버 OS 버전 및 서비스 버전이 공격자에게 노출될 수 있으며, 공격자는 이러한 정보를 통하여 해당 OS 및 서비스의 취약점을 이용하여 공격을 시도할 수 있음

**(B) 취약점 조치 방법**

- telnet 배너 설정 파일(`/etc/issue.net`)에 적절한 로그인 배너 메시지를 설정한 후 재시작
- vsftpd 설정 파일(`vsftpd.conf`)에서 `ftpd_banner` 지시자에 적절한 로그인 배너 메시지를 설정한 후 재시작
