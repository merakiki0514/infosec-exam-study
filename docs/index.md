## 빈출 파트 우선순위

기출 분석 결과, 매 회차 다음 순서로 출제 비중이 높습니다.

1. **위험 관리** — 매 회차 3~4문항 (위험처리 4가지, 위험분석 접근법, CIA, 재해복구, BCP/DRP, CC, ISMS-P)
2. **웹·애플리케이션 보안** — 매 회차 3~4문항 (XSS, SQL Injection, CSRF는 거의 매번 출제 + DNS/HTTP/이메일/DB/클라우드)
3. **네트워크 보안** — 매 회차 3~4문항 (DoS/DDoS, 스니핑, IDS, 포트스캔, TCP/무선랜)
4. **시스템 보안** — 리눅스/윈도우 실무 설정, 접근통제 모델, 유명 취약점
5. **침해사고 분석·대응** — Snort/iptables 실무, 취약점 점검 도구, 침해사고 시나리오 5종 (자주 간과되는 영역)
6. **암호화·인증** — SSL/TLS, PAM, 계정관리(EAM/IAM), 모바일 보안
7. **법·제도·실무** — iptables, sendmail, Apache 설정, 개인정보보호법 등 실무형 문제 다수

!!! note "교재 근거"
    개념 정리는 정일영 저 「정보보안기사 실기 이론편」(팀스핏 출판)의 목차 구성을 커버리지 기준으로 삼아 직접 재작성한 내용입니다. 원 교재의 문장을 그대로 옮기지 않고, 같은 사실관계를 저희 방식대로 표·요약으로 재구성했습니다.
