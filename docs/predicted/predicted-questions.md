# 예상문제 — 출제 가능 신규 토픽

[최종 총정리 페이지](../concepts/07-final-summary.md#회차별-신규-출제-토픽--연도별-트렌드)의 회차별 트렌드를 보면, 매 회차 새로운 지엽적 주제가 1~2개씩 추가되는 패턴이 보입니다. 아래는 **아직 기출에 나오지 않았지만 다음 회차에 나올 가능성이 있는 주제**를 선별하여 만든 예상문제입니다. 기출문제와 같은 형식(단답형/서술형/실무형)으로 구성했습니다.

전체 문항은 `data/questions.json` 문제 데이터베이스에 `"source": "예상"`으로 태깅되어 있으며, `/study` 일일 학습 세션에서도 출제됩니다.

!!! warning "주의"
    예상문제는 실제 기출문제가 아니라, 최근 출제 트렌드(인증·계정관리, 모바일 보안, 클라우드/컨테이너 보안 등으로 확장되는 경향)를 근거로 **추정**하여 만든 학습용 문제입니다. 기출문제 학습을 우선하고, 예상문제는 시간 여유가 있을 때 보충 학습용으로 활용하세요.

## 네트워크 보안

| 주제 | 문제 | 정답 요약 |
|---|---|---|
| Zero Trust | 제로 트러스트 보안 모델의 핵심 원칙과 경계 기반 보안과의 차이는? | "Never Trust, Always Verify" — 모든 요청을 매번 검증, 최소 권한 부여 |
| ARP Spoofing | 스위치 환경에서도 스니핑을 가능케 하는 ARP 캐시 오염 공격은? | ARP Spoofing |
| DHCP Starvation | 가짜 MAC 대량 요청으로 IP 주소 풀을 고갈시키는 공격과 대응은? | DHCP Snooping, Port Security |
| BGP 하이재킹 | 라우팅 경로 조작으로 트래픽을 우회시키는 공격은? | BGP Hijacking |
| 반사 증폭 공격 | 위조 IP로 제3서버를 경유해 트래픽을 증폭시키는 DDoS 유형은? | Reflection Amplification Attack |

!!! tip "학습 방법"
